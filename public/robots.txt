# 언제나가 — 누구나 긁어가도 된다. 막을 것은 로그인해야 보이는 곳뿐이다.
#
# 이 파일이 없으면 SPA 폴백이 index.html 을 돌려줘서, 크롤러가
# robots.txt 자리에서 HTML 을 받는다. 그러면 사이트가 잘못 설정된 것으로
# 읽힌다 — 애드센스 "사이트를 확인할 수 없습니다" 가 그래서 났다.
# (네이버 문서도 같은 말을 한다: robots.txt 가 HTML 로 오면 "없음"으로 친다)
#
# **Disallow 를 Allow 보다 먼저 적는다.**
# 표준(RFC 9309)은 "가장 긴 규칙이 이긴다" 지만, 옛 규약대로 "먼저 맞는
# 규칙"을 쓰는 수집기도 남아 있다. Allow: / 가 위에 있으면 그런 수집기가
# 그걸 먼저 집고 아래 Disallow 를 무시한다 — 파서에 물려보니 실제로
# /admin 이 허용으로 읽혔다. 순서를 뒤집으면 양쪽 해석이 같은 답을 준다.
#
# **아래 두 묶음은 내용이 같아야 한다.**
# 수집기는 이름이 가장 잘 맞는 묶음 하나만 읽고 나머지를 통째로 무시한다.
# Yeti 묶음을 만들면서 Disallow 를 빠뜨리면 네이버만 /admin 을 긁게 된다.
#
# 파비콘·자바스크립트·CSS(/assets, /favicon.svg)는 일부러 막지 않는다.
# 네이버 문서가 짚듯 수집기는 그것들을 문서의 일부로 보고, 막아두면
# 화면을 못 그려 엉뚱한 내용으로 해석한다.

# 네이버 수집기. 서치어드바이저가 이름을 명시하기를 권한다.
User-agent: Yeti
Disallow: /me
Disallow: /admin
Disallow: /auth/
Allow: /

# 그 밖의 모두 (구글·빙 포함)
User-agent: *
Disallow: /me
Disallow: /admin
Disallow: /auth/
Allow: /
